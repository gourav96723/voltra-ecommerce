# 🛒 Voltra — E-Commerce Platform

> **Web Development Internship Project — Uptricks Pvt. Ltd.**

Voltra is a modern **full-stack e-commerce web application** built as part of my Web Development internship.  
It provides a complete shopping experience with authentication, product browsing, cart, wishlist, checkout, orders and an admin dashboard.

---

## ✨ Features

- 🛍️ Product Catalog & Categories
- 🔎 Product Search & Filtering
- 🔐 User Authentication & Authorization
- 🛒 Shopping Cart
- ❤️ Wishlist
- 💳 Checkout & Payment Integration
- 📦 Order Management
- ⭐ Product Reviews & Ratings
- 👤 User Profile & Addresses
- 🧑‍💼 Admin Dashboard
- 📱 Responsive Design
- 🔒 Secure Backend APIs
